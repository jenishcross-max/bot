# Ролик для салонов (Remotion)

1080×1920, 30 fps, 37.6 с. Сцены расставлены по расшифровке озвучки
(`src/timeline.ts` — там же таймкоды фраз), поэтому картинка меняется
в паузах голоса, а не по ровным числам.

## Как собрать

```bash
npm install
npm run audio     # синтезирует music.wav и звуки в public/sfx
npm run render    # out/salon-reel.mp4
```

`public/voice.mp3` — озвучка из ElevenLabs. Заменить её можно на любую другую,
но тогда нужно пересчитать тайминги в `src/timeline.ts`: расшифровка с
таймкодами делается через whisper (см. `promo/voice-salon-prompt.md`).

## Что где

- `src/theme.ts` — единственное место с цветами, кривыми и пружинами.
- `src/timeline.ts` — тайминги сцен и склеек.
- `src/scenes/*` — восемь сцен ролика.
- `src/components/*` — слои кадра, движение, интерфейсные примитивы, иконки.
- `scripts/gen-music.mjs` — фоновая музыка, чистые синусы на нотах аккорда.
- `scripts/gen-sfx.mjs` — звуки: whoosh на склейках, pop на сообщениях, tick,
  thump на кнопке, shimmer в финале.

## Правка под конкретный салон

Имя салона, услуги, цены и имена клиентов лежат прямо в сценах:
`Chat.tsx`, `Prices.tsx`, `Telegram.tsx`. Менять их можно без пересборки
таймингов — длина фраз на картинке от голоса не зависит.
